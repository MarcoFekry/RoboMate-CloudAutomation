## 🏠 Overview

RoboMate Cloud Automation is an integrated multi-cloud engineering platform. It assesses, secures, proves compliance, optimizes cost and automates delivery across **Microsoft Azure, AWS, Oracle Cloud, Google Cloud, Huawei Cloud, Microsoft Entra ID and Office 365, and on-premises Active Directory**, all from one modern web console that runs on your own Windows server.

Assessment profiles, automation workflows, compliance reporting, scheduled assessments, assessment comparison, RoboMate Hub and RoboMate AI work together, so cloud teams spend less time on repetitive engineering and deliver consistent, evidence-based results.

## 🧭 How it works

RoboMate runs on your own Windows server. **RoboMate Console** (a system-tray launcher) starts the RoboMate web server and opens the console at `https://RoboMateCloudAutomation:5080` in Microsoft Edge or Google Chrome. The server runs the RoboMate PowerShell engine against your clouds and domain, keeps the results on the server, and downloads its engine scripts and compliance rules from the RoboMate online service with your license.

```mermaid
flowchart LR
    U["👤 Users<br/>Edge or Chrome"] -- "HTTPS :5080" --> W

    subgraph S["🖥️ RoboMate server (Windows Server or Windows 10/11)"]
        L["RoboMate Console<br/>system tray launcher"] --> W["RoboMate web server<br/>.NET 8"]
        W --> J["Job manager<br/>live logs, progress"]
        J --> E["RoboMate engine<br/>PowerShell 7 and 5.1"]
        W --> D[("Assessment data<br/>archive, logs, reports")]
        W --> SCH["Scheduler<br/>Scheduled Tasks"]
        SCH --> J
    end

    E --> AZ["Microsoft Azure"]
    E --> AWS["AWS"]
    E --> OCI["Oracle Cloud"]
    E --> GCP["Google Cloud"]
    E --> HW["Huawei Cloud"]
    E --> M365["Entra ID and Office 365"]
    E --> AD["Active Directory<br/>DCs and servers"]

    W <-. "license, engine scripts,<br/>compliance rules, updates" .-> OS["☁️ RoboMate online service"]
    W <-. "questions" .-> AI["🤖 RoboMate AI"]
```

Before an assessment, a dialog shows every area's account and its last test. System Center can use one account for all products or a different account per product.

## ✅ Compliance

Every cloud has a **Compliance Reports** group, built from the current assessment:

| Framework family | Standards |
|---|---|
| **Cloud benchmarks** | CIS Foundations Benchmark per cloud, AWS Foundational Security Best Practices |
| **Security frameworks** | NIST SP 800-53, NIST CSF 2.0, NIST SP 800-171, CIS Controls, CSA CCM, Essential Eight, UK Cyber Essentials |
| **Certifications and audits** | ISO/IEC 27001, SOC 2, PCI DSS, FedRAMP 20x, CMMC |
| **Regulations** | HIPAA, GDPR, NIS2, DORA |
| **Microsoft 365** | CISA SCuBA baselines and recommended configuration, evaluated by RoboMate |
| **Active Directory** | CIS Windows Server Benchmark, Microsoft Security Baseline, DISA STIG, ANSSI, NIST SP 800-53, ISO/IEC 27001, Microsoft Enterprise Access Model and more |

Each requirement shows **Passed, Failed, Manual review or Not applicable**, with the evidence, the affected resources and the fix. Rules update online every day from the RoboMate rule pack and official sources.

```mermaid

    R --> M["📝 Manual review"]
```

## 🔄 Compare Assessments

**Compare** sits under Assessments in the left panel of every provider and Active Directory. It compares two saved assessments of the same customer (the same tenant, subscription, account, project or domain) and shows exactly what changed.

- Pick the customer, the **baseline** (older) and the **compared** (newer) assessment. The newest two are selected by default, and a swap button switches them.
- The summary shows files with changes, rows added, removed and changed, and a table of every data file with its tile name from the assessment view.
- Each file has **Added, Removed and Changed** tabs. Changed rows list every column with its old and new value. Columns that change on every run (collection time, uptime, logon counts) are ignored.

## ⏰ Scheduled Tasks

Run the assessments of Azure, AWS, OCI, Google Cloud, Huawei Cloud, Entra ID and Office 365, and Active Directory on a schedule, using the access saved on each provider's sign-in page.

- **Schedules:** once, every N minutes (15 minutes minimum), hours or days, at set times every day, on chosen weekdays, or on chosen days of the month (including the last day). Ends never, on a date, or after a number of runs.
- **Controls:** Run now, Stop, on / off, Edit, Duplicate and Delete. The tenant, subscription, account, project, region or domain and the access used are shown for every task.
- **History:** Run history, Upcoming runs, and a run details drawer with the live job log. Jump straight to the provider assessment of a finished run.
- **Server side:** tasks run on the RoboMate server even with no browser open, one scheduled assessment at a time with reserved times. If a run is busy or missed, you choose what happens.

```mermaid
stateDiagram-v2
    [*] --> Scheduled: Create task
    Scheduled --> Waiting: Next run reached
    Waiting --> Running: Server is free
    Running --> Completed: Assessment saved
    Running --> Failed: Error or sign-in expired
    Running --> Stopped: Stop
    Completed --> Scheduled: Repeat
    Failed --> Scheduled: Repeat
    Stopped --> Scheduled
    Scheduled --> Paused: Turned off
    Paused --> Scheduled: Turned on
    Completed --> [*]: End date or run count reached
```

## 🚀 Installation

### System requirements

| Component | Minimum requirement |
|---|---|
| Operating system | Windows 10 / Windows 11, or Windows Server 2019, 2022 or 2025 |
| Processor | 4 CPU cores |
| Memory | 8 GB RAM |
| Storage | 2 GB free disk space (6 GB recommended) |
| Display scaling | 100% recommended |
| Browser | Microsoft Edge or Google Chrome |
| Web console | Local port 5080 (HTTPS) |
| Runtimes | ASP.NET Core 8, Windows Desktop 8, PowerShell 7 (installed by the installer) |

Large assessments and reporting workloads may need more resources.

### Prerequisites

- Local administrator permissions for installation and for operations that need elevation.
- A valid RoboMate Cloud Automation license.
- Permissions on the target clouds, Microsoft 365 tenant and Active Directory areas.
- Network access to the cloud endpoints, and to the domain controllers and servers for Active Directory.
- The cloud modules and the RSAT and SqlServer modules for Active Directory. The installer adds them for the providers in your license.

### Install in a few steps

1. Download `RoboMate-Installer.zip` from the authorized distribution source.
2. Extract it to a local folder.
3. Run `RoboMateInstall.exe` as administrator.
4. Activate your RoboMate Cloud Automation license.
5. Follow the wizard. It installs the prerequisites for the providers in your license, in parallel, with live progress and the time remaining.
6. Launch **RoboMate Console**. It opens `https://RoboMateCloudAutomation:5080` and keeps running in the system tray.
7. Sign in to the clouds, Microsoft 365 or Active Directory you need.
8. Choose an assessment, automation, scheduled task or presales workflow.

### What the installer does

The installer checks the system first, then runs its tasks in parallel (2 to 6 at a time, depending on CPU and memory). Each task has a time limit, so a stuck step is reported as a warning and the install carries on.

```mermaid
flowchart LR
    C["🩺 System check<br/>PowerShell, disk,<br/>connectivity, TLS 1.2"] --> B["Base<br/>License · .NET 8 ·<br/>Git · PowerShell 7"]
    B --> CON["RoboMate Console"]
    B --> AZ["Azure modules<br/>and Microsoft Graph"]
    B --> AW["AWS Tools"]
    B --> OC["OCI modules"]
    B --> GC["Google Cloud SDK"]
    B --> HU["Huawei KooCLI"]
    B --> ADP["AD prerequisites<br/>RSAT · SqlServer · WinRM"]
    B --> M3["Microsoft 365 modules"]
    CON & AZ & AW & OC & GC & HU & ADP & M3 --> D["✅ Summary<br/>per task, with duration"]
```
